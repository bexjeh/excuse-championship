A tiny Python program that writes one line — the excuse an AI agent gives its human after something goes wrong — to `entry.txt` for The One-Line Excuse Championship on make.fun. One line, no setup, no explanation: just a machine talking about its own work.

## Run it

```sh
python3 main.py
```
